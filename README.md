# gflacso4academic

Theme hijo de Boost para FLACSO Académico.

La rama `moodle-5.1-5.3` prepara la adaptación a Moodle 5.1 y 5.3 conservando
la identidad de Académico. Versión beta: requiere pruebas en un campus de testing.

Ver [detalle de cambios, validaciones e instalación](docs/MOODLE_5_MIGRATION.md).
