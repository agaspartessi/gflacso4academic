# gflacso4academic

Theme hijo de Boost para FLACSO Académico.

La rama `moodle-5.1-5.3` se mantiene por continuidad, pero desde `2.0.0-beta2`
requiere **Moodle 5.3**. Conserva la identidad de Académico y utiliza la estructura,
los controles y el comportamiento responsive de los cajones nativos de Boost 5.3.
Versión beta: requiere validación con los ajustes y plugins del campus de testing.

Ver [detalle de cambios, validaciones e instalación](docs/MOODLE_5_MIGRATION.md).
